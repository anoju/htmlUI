1. Lua 스크립트 핵심 문법 대조표

자바스크립트나 일반 언어에 익숙한 개발자가 루아 소스코드를 처음 볼 때 헷갈리기 쉬운 연산자와 기본 문법의 차이점입니다.

비교 항목 JavaScript 문법 스마트 폼디 Lua 문법 주요 특징 및 주의점
주석 (Comment) // 단일행
/* 다중행 */		 -- 단일행
--[[ 다중행 ]]--		 하이픈 두 개(--)로 시작합니다.
대입 연산자 = = 동일합니다.
비교 연산자 ==, !=, === ==, ~= 같지 않음은 ~= 입니다. !=는 문법 에러를 유발합니다.
문자열 연결 + 또는 `tpl ${val}` .. 문자열 결합은 반드시 .. 연산자를 사용해야 합니다.
빈 값 / 널 null, undefined nil 값이 비어있거나 객체가 정의되지 않았으면 nil입니다.
논리 연산자 &&, ||, ! and, or, not 영어 단어 그대로 사용합니다. (예: if a and not b then)
지역 변수 let, const local 함수나 블록 내에서만 유효한 변수는 local로 선언합니다.
중요 (1-Based Indexing): 루아에서는 배열(Table)의 인덱스가 0이 아닌 1부터 시작합니다. 루프를 돌거나 첫 번째 요소에 접근할 때 tArray[1]을 사용해야 함에 극히 유의해야 합니다.

2. JSON 데이터 파싱 및 테이블(Table) 제어

서버나 다른 모듈로부터 수신한 JSON 문자열 파라미터를 파싱하고 테이블 구조로 순회하는 상세 코드 가이드입니다.

1) JSON 문자열 파싱 (json.parse)

전달인자로 넘어온 sParam이 JSON 포맷 문자열일 경우, Lua 테이블로 변환하는 정석 코드입니다.

-- sParam: {"acct_info": {"accno": "1234", "acct_type": "RIA", "pnsn_no": nil}}
local sLen = string.len(sParam) -- 문자열 길이 계산

-- json.parse(대상스트링, 시작위치, 파싱할길이)
local tJson = json.parse(sParam, 1, sLen)

if tJson == nil then
    print("JSON 파싱 에러 발생")
    return
end

local tAcct = tJson["acct_info"]

2) 테이블(Table)의 유형과 다루는 법

루아는 유일한 자료구조로 테이블을 제공합니다. 이는 Key-Value 맵(객체)과 인덱스 리스트(배열) 역할을 모두 수행합니다.

Key-Value 맵 형태

키를 이용해 값에 접근하거나 테이블 속성 형태로도 조회할 수 있습니다.

local tMap = {}
tMap["key"] = "value"
tMap.name = "홍길동" -- . 연산자 가능

print(tMap["key"]) -- 출력: value
print(tMap.name)   -- 출력: 홍길동

인덱스 배열 형태 (1-based)

배열 크기는 # 기호를 붙여 구하며, 순회 시 ipairs를 사용합니다.

local tList = {"Apple", "Banana", "Cherry"}

print(#tList) -- 출력: 3 (배열의 크기)
print(tList[1]) -- 출력: Apple (첫번째 요소)

-- 순차 순회 (index, value)
for idx, val in ipairs(tList) do
    print(idx .. ": " .. val)
end

3. 비동기 TR 통신 및 계층형 UI 컴포넌트 제어

네이티브 폼디 통신 API(SendTransaction 등) 호출 예제와 컴포넌트 속성(visible, caption)을 연동하는 실전 프로세스입니다.

호출

1) 입력값 체크 및 파라미터 JSON 구성 후 TR 요청

입력 컴포넌트의 텍스트가 유효한지 확인하고 파라미터를 인코딩하여 비동기 전송을 보냅니다.

function f_RequestStockSearch()
    -- UI 컴포넌트 텍스트 획득
    local sCode = edtStockCode.text
    
    if sCode == nil or sCode == "" then
        MessageBox("종목코드를 입력해주세요.")
        return
    end

    -- 요청 데이터 테이블 선언
    local tReq = {}
    tReq["stock_code"] = sCode
    tReq["search_type"] = "1"

    -- 테이블을 JSON 문자열로 인코딩
    local sParam = json.stringify(tReq)

    -- 통신 공통 함수 호출 (TR코드, 입력파라미터, 콜백함수명)
    SendTransaction("TR_STOCK_PRICE_SEARCH", sParam, "OnTrCallback")
end
콜백

2) 콜백 함수 분석 및 계층형 UI 제어

수신된 데이터를 기반으로 특정 UI 컨테이너의 가시성을 변경하고, 라벨에 텍스트를 대입합니다.

-- 비동기 통신 콜백 함수 정의
function OnTrCallback(sTrId, nErrCode, sErrMsg)
    if nErrCode < 0 then
        MessageBox("통신 실패: " .. (sErrMsg or "알 수 없는 에러"))
        return
    end

    if sTrId == "TR_STOCK_PRICE_SEARCH" then
        -- 캡처화면 계층형 UI 조작 유형
        -- 1) visible 속성을 이용한 컴포넌트 가시화 및 은폐
        contScrollV.visible = true
        contStart.visible = false
        
        -- 2) JSON 파싱 후 라벨 caption 갱신
        local tResult = json.parse(sErrMsg, 1, string.len(sErrMsg))
        local sPrice = tResult["price"]
        
        contScrollV.lblCurrentPrice.caption = sPrice
        
        -- 3) 그리드나 리스트 뷰가 비어있을 때 에러 메시지 설정
        if tResult["count"] == 0 then
            contScrollV.pannList.SetEmptyMessage("해당 조건의 데이터가 없습니다.")
        end
    end
end

4. 루아 스크립트 예외 예방 (Defensive Coding)

루아 스크립트 실행 중 자주 터지는 런타임 오류(Crash)를 예방하고 소스 코드의 신뢰성을 높이기 위한 설계 기법입니다.

1. "attempt to index a nil value" 방지

중첩된 테이블(예: tObj.subObj.value)을 검사할 때, subObj가 nil인 경우 즉시 크래시가 발생합니다. 단축 평가(Short-circuit evaluation)를 이용해 널체크를 연속적으로 수행해야 합니다.

-- 위험한 코드
local val = tAcct["sub"]["accno"] -- sub가 nil이면 에러!

-- 안전한 방어 코드
local sAccNo = ""
if tAcct and tAcct["sub"] and tAcct["sub"]["accno"] then
    sAccNo = tAcct["sub"]["accno"]
end

2. 산술 연산 시의 nil 대리값 지정

연산식(+, -, *, /)의 대상 중 하나라도 nil일 경우 스크립트 실행이 중단됩니다. or 키워드를 사용하여 기본값(Default)을 명시적으로 대리 지정해 줍니다.

-- 위험한 코드
local total = g_nQryTp + tData["count"] -- count가 nil이면 에러!

-- 안전한 방어 코드
-- count가 nil일 경우 0으로 자동 치환
local total = (g_nQryTp or 0) + (tData["count"] or 0)

5. HTS/MTS 루아 소스 분석 치트시트 (Cheat Sheet)

실제 소스 코드를 열었을 때 특정 변수나 함수를 즉시 역추적하여 흐름을 찾아내기 위한 키워드 사전입니다.

해당 컴포넌트의 ID(예: lblInvestingTitle)를 프로젝트 폴더 전체에서 검색한 후, 그 뒷부분에 .visible = false 또는 .visible = true 가 선언된 라인을 일괄 필터링합니다. 조건문(`if then`) 블록에 걸쳐있는 로직을 함께 스캔하여 비즈니스 분기 기준을 밝혀냅니다.

통신 요청 함수(예: SendTransaction)에 두 번째 매개변수로 들어가는 변수명을 추적합니다. 해당 변수가 json.stringify(tReq) 형태로 인코딩되기 전에 tReq["컬럼명"] = 값 형식으로 대입되고 있는 블록을 찾아내면 서버로 송신되는 데이터 스키마를 정의할 수 있습니다.

루아 테이블은 일반적인 `print(tAcct)`로는 메모리 주소값(table: 0x...)만 출력됩니다. 테이블 내부의 값을 사람이 읽을 수 있게 출력하려면 반드시 print(json.stringify(tAcct)) 또는 해당 솔루션이 제공하는 JSON 스트링 변환 유틸을 사용해 텍스트로 인코딩한 뒤 찍어야 합니다.
